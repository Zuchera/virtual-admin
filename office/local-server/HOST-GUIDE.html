Zuchera Local Server: run your office with no internet

One computer (the host) runs this program. Everyone else just opens a web address in their browser. No installs for the team.

You need: a computer that stays on, connected to the same Wi-Fi or cable network as your team (the network does not need internet), and Node.js (free, host only).

For the host (once)

  1. Unzip this whole folder somewhere permanent, such as Documents.
  2. Double-click Start Zuchera (Windows).bat or Start Zuchera (Mac).command (Linux: run start-linux.sh). If Node.js is missing, it opens the download page: install the LTS version and double-click again.
  3. If your computer asks whether to allow network access, choose Allow.
  4. The window shows the addresses to share, like http://192.168.1.20:8080. Leave that window open while people work.
  5. Open the address yourself and create the first account. You become the owner.
  6. Press Admin → Members and approvals to approve people, or create an invite link so they walk straight in.

For your team

  1. Connect to the same network as the host.
  2. Open the address the host gives you, create an account (or sign in), wait to be approved if asked.
  3. Optional: in Chrome or Edge, choose ⋮ → Install, so it opens like an app.

Voice and video

Browsers only allow the microphone and camera on secure pages. Use the https address shown in the host window (for example https://192.168.1.20:8443). Each person's browser warns once: choose Advanced, then Continue. Text chat, presence, boards and lessons work on the plain address.

Good to know

  • If the host computer is off or asleep, the office is unavailable. Turn off sleep while people work.
  • Everything is saved in the data folder next to the program, with a daily copy in data/backups. Copy that folder to move or back up your office.
  • Your plan: the first 14 days include every feature. To use a paid plan, the owner pastes the licence key in Admin; if it names a site, set the same name as "site" in config.json.
  • Settings (name, port, sign-up rules, file size) are in config.json. Restart the program after changing it.
  • Needs internet, so unavailable offline: AI notes, Slack, calendar links, YouTube and other web embeds.
  • If the address changes after a restart (some routers do this), share the new address shown in the window. A fixed address can be set in your router.

If something goes wrong

  • People cannot open the address: check they are on the same network, and that the host allowed network access when asked (firewall).
  • "Port already in use": change port in config.json.
  • Forgot a password: Admin → Members → reset password.
