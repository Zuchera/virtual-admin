Using Zuchera offline

Pick the option that matches how you work. All three give you the same office, buildings, gym, chess, karts and classrooms.

Which do I need?
Just me, or a practice run, on one computer → Option 1.
A team in one building or on a private network → Option 2.
A team who sign in from anywhere, with an install-like app → Option 3.

Option 1: one file, no internet at all

  1. Download StartDotCom-HQ.html (a single file) to your computer.
  2. Double-click it. It opens in Chrome, Edge, Firefox or Safari.
  3. Choose a name and a look. Done. Everything is inside the file, and your settings are saved in that browser.

Works: walking, all floors and lifts, gym, chess against the computer, karts with bots, classrooms and whiteboards on your own screen, notes, location clocks.

Does not work without a server: seeing other people live, shared chat, shared boards. Those need Option 2 or 3.

Option 2: team office on your own network (no internet needed)

  1. Choose one computer to be the host (it must stay on).
  2. Copy the deploy folder to it. Open a terminal inside the folder and run python3 -m http.server 8080 (or any static web server).
  3. Find that computer's address (for example 192.168.1.20). Everyone on the same network opens http://192.168.1.20:8080.
  4. For shared live data, set up the free self-hosted database described in README.md (Supabase running on your own server) and put its address in config.js.

Option 3: install it like an app (works offline after the first visit)

  1. Follow README.md to host the deploy folder (Vercel, your WordPress hosting, or any web host with HTTPS).
  2. Each person opens the address once while online. The office files and 3D models are saved on their device.
  3. In Chrome or Edge choose ⋮ → Install Zuchera (Safari: Share → Add to Home Screen). It now opens from the desktop or phone and loads with no internet.
  4. When the connection returns, live features (people, chat, boards) reconnect on their own.

WordPress plugin

  1. WordPress admin → Plugins → Add New → Upload Plugin → choose startdotcom-hq.zip → Activate.
  2. Open the new StartDotCom HQ menu and follow the on-screen setup. Everything is stored in your own WordPress database. Nothing is sent to anyone else.

If something looks wrong

  • Slow or choppy? Open 🎚 Comfort and switch on Lite mode.
  • Sound clashing? Press the 🔇 button in the top bar to stop all music and announcements.
  • A window in the way? Drag it by its ⋮⋮ grip, press – to fold it away, or × to close it.
